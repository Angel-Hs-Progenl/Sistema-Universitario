# Recursos de identidad

- `ut-oficial.png`: copia sin edición del PNG entregado por el líder. Su SHA-256 coincide con el original de la raíz. Uso en el portal sujeto a las autorizaciones institucionales; no se redistribuye bajo una licencia nueva.
- `azor.svg`: marca vectorial original propuesta para este portal, a partir de la mascota indicada por el líder. No se presenta como sustituto del escudo oficial ni como nueva identidad aprobada de la universidad.
- `azor-wordmark.svg`: versión horizontal para documentación, con texto editable “UT de Oriental”. La aplicación sirve el símbolo y texto HTML para preservar legibilidad y accesibilidad.
- `google-g.png`: recurso original obtenido de https://developers.google.com/static/identity/images/g-logo.png. Se utiliza únicamente en el botón de acceso según https://developers.google.com/identity/branding-guidelines. Sus colores pertenecen al proveedor; no amplían la paleta del sistema.

El PNG institucional no se recolorea ni deforma. El giro ocurre entre dos caras independientes del header. La marca del azor debe comprobarse al menos a 24, 32 y 44 px. El giro no bloquea el acceso y se puede desactivar desde el footer, según CR-006.

CR-008: src/modules/auth/UniversityScene.jsx es una ilustración SVG original de un azor geométrico entregando documentos, creada para la bienvenida común. Se sirve como código React y usa los tokens del sistema. No es un escudo, sello, título oficial o recurso copiado de Laravel. La propuesta de mascota conserva el carácter gráfico pendiente de revisión institucional.

CR-009 sustituye el ave geométrica por el dibujo original de Goshawk.jsx, con proporciones y rasgos de azor consultados en SEO/BirdLife y Cornell Lab. Fuentes y decisiones en docs/DISENO.md. Las fotografías se usaron solo como referencia visual, sin descargarlas, incorporarlas o calcarlas. El logo del encabezado permanece independiente de esta ilustración.
