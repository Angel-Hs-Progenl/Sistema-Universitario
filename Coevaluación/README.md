# Prototipo recibido

El HTML, CSS y JavaScript de esta carpeta llegaron en el commit `6449fdd` y sirvieron como referencia de criterios, escala y tareas. La versión integrada está en `src/modules/coevaluacion/` y `backend/app/modules/coevaluacion/`.

Se retiró la página independiente porque permitía cambiar de rol desde un botón y guardaba respuestas en `localStorage`. El flujo actual usa el Shell, la sesión y los permisos del servidor. Consulta [la especificación de integración](../docs/COEVALUACION.md).
